Turn 8 · the work window
The Work window rebuilt on the v7 chrome: five tabs — All, Render jobs, Training, Publish, Settings — and a card for every job instead of a text row. Every number, status sentence and log line is kept from the current build; only the container changed. A card is clickable: 8f is what opens, with the tile's location, its frames and its log. Machine state stays in one strip at the top of every tab so you always see what this machine is doing; the settings that cause it live in the Settings tab.
